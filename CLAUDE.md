# CLAUDE.md

Before writing code in this repo, read and follow:

- [docs/development-rules.md](docs/development-rules.md) — naming (snake_case variables, camelCase functions, PascalCase types/components), strict typing, SOLID, TDD, Prettier, commits.
- [docs/README.md](docs/README.md) — índice de búsqueda: qué documento responde qué. Busca con `rg -i "<término>" docs/ openspec/` en lugar de leer archivos enteros.
- [docs/design-system.md](docs/design-system.md) and [docs/branding.md](docs/branding.md) for any UI work.
- OpenSpec changes in `openspec/changes/` describe the work in progress; keep `tasks.md` up to date.

Commits: Conventional Commits, one logical chunk per commit, no attribution trailers.
