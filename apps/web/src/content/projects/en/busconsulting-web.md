Dynamic Busconsulting website, with its content stored in a database.

### Context

The company needed its own site whose content could change without rebuilding the pages.

### Challenge

A clear site for its clients that the team could maintain easily.

### Technical decisions

- Interface in HTML, CSS and JavaScript.
- PHP backend with MySQL for the content.
- Content managed from a dedicated desktop application.

### Outcome

A dynamic website maintained by the company’s own team.
