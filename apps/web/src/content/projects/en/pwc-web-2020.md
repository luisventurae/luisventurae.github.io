Migration of the Pool Work Confort website to Nuxt and Vue.js.

### Context

The brand's website, which presents its pool covers and products, needed to load faster and rank better in search engines.

### Challenge

Change the technology underneath without losing content or rankings, and leave the site easy to maintain.

### Technical decisions

- Nuxt and Vue.js frontend for a fast, indexable site.
- PHP backend with SQL Server.
- SEO and user experience improvements, on desktop and mobile.

### Outcome

A noticeably faster site, better prepared for search engines and easier to maintain.
