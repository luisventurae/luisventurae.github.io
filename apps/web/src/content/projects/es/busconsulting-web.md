Sitio web dinámico de Busconsulting, con su contenido guardado en base de datos.

### Contexto

La empresa necesitaba un sitio propio cuyo contenido pudiera cambiar sin rehacer las páginas.

### Reto

Un sitio claro para sus clientes y fácil de mantener por el equipo.

### Decisiones técnicas

- Interfaz con HTML, CSS y JavaScript.
- Backend en PHP con MySQL para el contenido.
- Administración del contenido desde una aplicación de escritorio propia.

### Resultado

Un sitio web dinámico, mantenido por el propio equipo de la empresa.
