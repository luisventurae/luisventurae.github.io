Application de bureau permettant au personnel de Busconsulting d’administrer son site web.

### Contexte

Le contenu du site vivait dans une base de données que l’équipe ne pouvait pas modifier sans connaissances techniques.

### Défi

Donner à l’équipe un outil simple, à l’accès protégé, pour maintenir le site.

### Décisions techniques

- Application de bureau en Java, développée avec NetBeans.
- Base de données MySQL partagée avec le site web.
- Accès par nom d’utilisateur et mot de passe.

### Résultat

Le personnel administre le site depuis sa propre application, sans dépendre d’un développeur.
