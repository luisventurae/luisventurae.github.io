Site web dynamique de Busconsulting, dont le contenu est stocké en base de données.

### Contexte

L’entreprise avait besoin de son propre site, dont le contenu puisse changer sans refaire les pages.

### Défi

Un site clair pour ses clients et facile à maintenir par l’équipe.

### Décisions techniques

- Interface en HTML, CSS et JavaScript.
- Backend PHP avec MySQL pour le contenu.
- Gestion du contenu depuis une application de bureau dédiée.

### Résultat

Un site web dynamique, maintenu par l’équipe de l’entreprise elle-même.
